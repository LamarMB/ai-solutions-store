## 2. Развёртывание витрины (без приёма заявок и индексации)

- [ ] **Р.** Сервер по `deployment-plan.md`: пользователь `app`, файрвол, SSH по ключам,
      Node.js 24, systemd, Node.js только на `127.0.0.1`.
- [ ] **Р.** nginx: https (Let's Encrypt), перезапись `X-Forwarded-For` и `X-Real-IP`,
      `client_max_body_size 1m`, HSTS.
- [ ] **Р.** Сборка с `SITE_URL=https://<домен>` и **без** `SITE_INDEXING=true`.
- [ ] **Р.** Проверить: `robots.txt` — `Disallow: /`, заголовки `X-Robots-Tag`,
      `X-Frame-Options`, `Content-Security-Policy`, `Strict-Transport-Security`.
- [ ] **Р.** Мониторинг доступности и оповещения; ротация логов.
- [ ] **В.** Ручная проверка на своём компьютере (Windows) и телефоне:
  - [ ] Главная → Каталог → фильтр → решение → выбор пакета → заявка (тестовый режим).
  - [ ] Каталог → AI Accounting Department → «Обсудить решение» → заявка: статус
        «В разработке» виден на всех шагах.
  - [ ] Главная → «Подобрать с ИИ» → описание задачи → рекомендация → решение → заявка;
        интерфейс сообщает «не ИИ», концепции помечены.
  - [ ] Плашка «Приём заявок ещё не запущен» видна; сообщение после отправки —
        «Проверка пройдена — заявка не отправлена».
