# План до первой платной клиники

Аудит 28.10.2026. Основание — `docs/tariff-audit.md` (готовность) и
`docs/pricing-economics.md` (цены). Часы — разработка с тестами одним разработчиком;
юридическая работа и продажи — отдельно, без часов разработки.

## 1. Коротко

- **Продавать первым:** «Старт» (бот, справочник, обращения, панель). «Оптимум» — только
  клинике **без МИС**. «Бизнес» и интеграцию МИС — не продавать до первой интеграции.
- **До первого клиента:** ~**90–160 ч** разработки (P0) — 2–4 недели одного разработчика —
  и параллельно юридический пакет.
- **Главные блокеры:** бот и Mini App работают только с тестовыми аккаунтами и с
  пометками «демо» в коде; сайт не опубликован; правовая база не готова; размещение
  данных в РФ не подтверждено; резервные копии — вручную на том же сервере.

Плюс 8–12 ч на непредвиденное → **~90–160 ч**. Для клиента только на «Старт» P0-2 не
нужен (−8–12 ч).

**P0 вне разработки (владелец и юрист):**

1. Юрист по 152-ФЗ и 323-ФЗ: роли (клиника — оператор, мы — обработчик по поручению?),
   договор поручения, политика, тексты согласий, уведомление Роскомнадзора,
   трансграничная передача текста в OpenAI (или режим без OpenAI), врачебная тайна при
   переписке во ВКонтакте.
2. Договор-оферта и счёт: реквизиты, порядок оплаты, SLA (время реакции поддержки).
3. Цены на сайте: сейчас 3 900 ₽/мес у «Старта» убыточно (`pricing-economics.md`, 4).
4. Коммерческое предложение и честная демонстрация: что работает, что нет
   (`docs/demo-readiness.md`).
