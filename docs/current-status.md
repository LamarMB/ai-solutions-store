## Известные проблемы и ограничения

- **Конфиденциальность во ВКонтакте не решена:** руководители сообщества потенциально
  видят всю переписку пациента; перенос медицинского чата на отдельный сайт владелец
  сейчас отклонил (`docs/decisions.md`, Р-08, Р-09).
- Текст сообщений уходит в OpenAI при заданном ключе (телефоны и почта вырезаются).
- Владелец технически может выдать себе роль врача (видно только по журналам).
- Ограничение попыток входа в панель хранится в памяти процесса.
- Сайт: заявки в тестовом режиме, `/privacy` — заглушка, индексация выключена;
  ожидается обновление безопасности Next.js и есть `npm audit` в dev-цепочке ESLint
  (`docs/roadmap.md`, «Открытые вопросы»).
- Все данные вымышленные; реальные персональные данные не собираются.
